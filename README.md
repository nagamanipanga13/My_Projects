# Hiring Process Simulation – Java

## About the Project
This project simulates an HR recruitment phone call using Java. It interacts with the candidate through console input and output and checks eligibility based on different recruitment criteria.

## Features
- Candidate name confirmation
- Availability for HR call
- Academic eligibility verification
- Graduation branch verification
- Technical skill verification
- Work experience verification
- Academic or personal project details
- Relocation willingness
- Salary expectations
- Immediate joining availability
- Final selection process message

## Technologies Used
- Java
- Scanner class
- Conditional statements (if-else)
- String methods
- Nested if-else
- User input handling

## How It Works
The program takes candidate information from the console and checks the eligibility criteria step by step.

Based on the candidate's answers, the program displays appropriate HR responses and determines whether the candidate can proceed to the next round.

## How to Run
1. Clone or download this repository.
2. Open the project in Eclipse IDE.
3. Run the `HiringProcess.java` file.
4. Enter the required details in the console.
